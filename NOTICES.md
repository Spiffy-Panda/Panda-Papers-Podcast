## Embedded web assets

The arXiv-saved HTML packages under `SteeringFollowup/*_files/` include
small amounts of third-party CSS/JS (Bootstrap, MIT; arXiv/ar5iv style
assets, permissive). These are present only as page assets to make the saved
HTML render correctly. If the repository is ever published as a release
artifact rather than a personal working tree, these should be replaced with
fresh fetches from upstream rather than redistributed wholesale.
